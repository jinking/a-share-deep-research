## 四、修正的 3 处判断（核心价值）

### 修正1：经营现金流为负 → 风险等级 高 → 中低

原判断："经营现金流-24.46亿，净现比-31.19%" → 列为**重大财务风险**

融合后的完整图景：
| 项目 | 数据 | 含义 |
|---|---|---|
| H1经营现金流 | -24.46亿 | 表面看是负 |
| **Q2单季经营现金流** | **+46.22亿** | ✅ **已回正** |
| 销售收款/当期营收 | **100.09%** | ✅ 回款正常 |
| 季节性 | H1淡季需付上年Q4到期货款 | ✅ 正常周期 |
| 战略性备料 | 超50亿（主动提前采购） | ✅ 主动选择 |
| 存货增幅 | +18.98% **< 营收+40.16%** | ✅ 库存健康 |

**修正**：现金流为负主要是**季节性 + 主动备料**，非经营恶化。Q2单季回正46.22亿 + 回款率100.09% 直接证伪"现金流危机"。**风险等级：高 → 中低**。（但现金运营周期+7.58天是客观事实，保留在证伪指标中。）

### 修正2：并购商誉风险 → 中 → 低

新数据：**商誉仅22.39亿元**，占净资产1.97%，占总资产0.64%，较2025年末基本持平。
→ Leoni 等并购**主要以有形资产/技术/客户资源入账，未形成巨额商誉**。**风险：中 → 低**（利好修正）。

### 修正3（新增遗漏项）：股权质押 14.07%

原报告完全缺失。融合后拿到：
- 全公司质押股份 **14.07%**
- 第一大股东立讯有限公司质押 **10.33亿股，占其持股37.83%**

→ 遗漏的**治理风险点**。虽未达警戒线，但股价从81元跌至52元（-35%）时存在质押压力。**补充等级：中。**

## 七、可复用的教训

1. **接到需求先探技能清单**，不要直接搜（首次就是错在这里）
2. **技能侧财务入库滞后1季度**是常态，最新财报必须搜
3. **现金流为负必须做单季拆解**，累计数会误导
4. **股权质押必须单独查**，技能侧没有，最易漏
5. **商誉要看绝对额和占比**，不能因"有并购"就假定商誉高
6. **交叉验证是免费的保险**，14项一致才敢下结论
7. 本技能的通用性已在**亨通光电（sh600487）**上验证：8年数据准确，质量校验自动捕获异常（2025营收+11.45% vs 归母-3.21%，背离14.7pct）
