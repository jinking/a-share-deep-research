# 搜索与证据规则

## 一、资料优先级

从高到低：
1. 公司公告、年报、季报、交易所文件
2. 交易所互动、投资者关系活动记录、业绩说明会
3. 公司官网与产品资料
4. 政府、行业协会、权威数据库
5. 上下游客户/供应商公告
6. 券商研报
7. 高质量财经媒体
8. 社交媒体/传闻（仅做线索）

规则：
- 一手资料优先
- 关键结论尽量至少两处独立来源交叉验证
- 无法确认的数据明确标注 `【无法确认】`
- 券商预测不得当事实
- 管理层口径不得等同已经兑现
- 二手来源若共同转引同一原始来源，不算独立交叉验证

## 二、必搜清单

1. 最新一期财报：营收、归母、扣非、利润率、ROE、经营现金流
2. 分业务收入/毛利率/增速
3. 利润质量：汇兑、一次性、费用率、并表、政府补助
4. 业绩预告/经营目标/管理层指引
5. 核心子公司与并购标的经营
6. 客户与大客户资本开支/出货/订单
7. 新业务：收入、订单、定点、送样、在研分别处于什么层级
8. 行业景气：行业价格、产量、渗透率、政策、技术路线
9. 股权质押、减持、解禁、控制权变化
10. 竞争格局、市场份额、竞争对手财务对比
11. 产能、在建工程、资本开支和融资计划
12. 未来6–18个月催化剂/重大风险

## 三、证据账本模板

| ID | 结论/数字 | 数值/内容 | 期间/时点 | 证据标签 | 原始来源 | 发布时间 | 第二来源 | 状态 |
|---|---|---|---|---|---|---|---|---|
| C01 | | | | 【事实】 | | | | 已验证/待验证/冲突 |

每个会影响“盈利预测、估值、风险等级、研究状态”的结论，尽量进入证据账本。

## 四、时效性规则

研究开始时先写清：
- 今天日期
- 最新财报报告期
- 最新公告日期
- 当前股价/市值的时点

若结构化数据停留在旧报告期，不得用它覆盖更新的一手财报。

## 五、冲突处理

出现两个数字不一致时，按以下顺序排查：
1. 是否报告期不同
2. 是否单位不同
3. 是否合并口径/母公司口径不同
4. 是否包含票据、少数股东、非经常性损益等口径差异
5. 是否数据修订
6. 是否二手媒体录入错误

不能直接平均，也不能选择“更符合预期”的那个数字。
